# Apna Khet: AI-Driven Crop Health Analytics & Disease Detection Portal 🌾

An intelligent, AI-assisted smart agriculture web portal designed to empower farmers with real-time crop disease detection and automated diagnostic analytics.

## 📌 Project Overview
The **Apna Khet** project bridges modern machine learning technology with agriculture. By leveraging interactive image classification models, the platform identifies crop diseases early, helping farmers take preventive measures and optimize agricultural yields.

* **Project Title:** Apna Khet: AI-Driven Crop Health Analytics & Disease Detection Portal
* **Core Objective:** Provide an automated, accessible system for early crop disease detection and smart farming insights.
* **Technology Stack:** TensorFlow.js, Teachable Machine Models, Node.js, and Google Apps Script.

---

## ⚙️ Key Features & Architecture

1. **AI-Powered Image Classification:** Utilizes pre-trained TensorFlow.js and Teachable Machine models to process crop leaf images and instantly detect symptoms of disease.
2. **Automated Backend Workflow:** Powered by Node.js for handling server-side requests and data routing.
3. **Google Apps Script Integration:** Connects frontend inputs seamlessly with cloud spreadsheets and automated data logging.
4. **Farmer-Friendly Interface:** Built with a clean, responsive layout ensuring ease of use for rural and semi-urban agricultural stakeholders.

---

## 🛠️ Technology Stack
* **Frontend / ML:** HTML5, CSS3, JavaScript, TensorFlow.js, Teachable Machine
* **Backend:** Node.js
* **Automation & Cloud:** Google Apps Script, Google Sheets
